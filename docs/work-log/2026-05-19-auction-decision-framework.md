# 2026-05-19 경매 판단 프레임 문서화

## 작업 내용
- 사용자가 경매 데이터를 통해 실제로 얻으려는 판단 질문을 기준으로 서비스 기획을 재정리했다.
- 가격 판단, 물건 실체 판단, 경매 진행 이력, 명세서 리스크, AI 분석으로 데이터 영역을 나눴다.
- 목록/상세 화면에서 어떤 정보를 어떤 우선순위로 보여줄지 정의했다.
- 향후 작업 전 확인해야 하는 기준 질문을 문서화했다.

## 오류 증상
- 기능이 사용자 지시에 따라 필드 단위로 뒤늦게 추가되고 있었다.
- “이걸 보는 사람이 무엇을 판단하려는가”에 대한 기준 문서가 없어서 UI와 데이터 제공 방식이 산발적이었다.

## 원인
- 수집 안정화에 끌려가면서 제품 판단 프레임을 먼저 고정하지 못했다.

## 조치
- `docs/superpowers/specs/2026-05-19-auction-decision-framework.md` 작성.
- 이후 기능 추가 기준을 “판단 질문에 답하는가”로 정했다.

## 검증
- 문서에 가격/실체/이력/명세서/AI 분석 영역이 모두 포함되어 있는지 확인했다.
- 각 영역별 현재 상태와 필요한 데이터가 분리되어 있는지 확인했다.

## 결과/남은 확인
- 다음 구현은 이 문서를 기준으로 Phase 2: 경매 판단 데이터 추출부터 진행하는 것이 맞다.
- 크롤러 안정성을 흔드는 변경은 별도 계획 없이 하지 않는다.
