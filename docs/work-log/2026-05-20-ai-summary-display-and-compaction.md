# 2026-05-20 AI 요약 표시 및 명세서 입력 정제

## 증상
- 화면에서는 AI 요약이 10건 이상 처리된 것처럼 보였지만, 실제 상세/목록에서 유의미한 요약이 보이지 않았다.
- 매각물건명세서 원문에는 법원 공통 안내문, 개인정보 경고, 부동산 표시/층별 면적/가격표가 길게 포함되어 로컬 LLM 처리 시간이 길었다.

## 확인 결과
- DB 기준 실제 AI 성공은 2건, 실패는 11건이었다.
- API가 enrichment 레코드 존재 여부만 보고 `completed`로 표시해 실패 건까지 완료로 집계했다.
- 목록 카드는 AI 완료 여부 배지만 보여주고 요약 제목/핵심 bullet/리스크 코멘트를 표시하지 않았다.

## 조치
- API에서 `status='success'`인 enrichment만 완료로 간주하도록 수정했다. 실패 건은 `failed`로 분리하고 오류 메시지를 내려준다.
- 목록 카드에 AI 요약 제목, 핵심 bullet 2개, 리스크 코멘트를 표시하도록 했다.
- 상세 화면도 AI 실패 상태를 완료와 분리해 보여준다.
- 매각물건명세서 AI 입력에서 공통 안내문, 개인정보 경고, `부동산의 표시` 이후 장문 영역을 제외한다.
- 모델이 반환한 `<b>...</b>` 같은 HTML 태그는 저장 전 제거한다.
- 프롬프트 입력 규칙 변경으로 `INSIGHTS_PROMPT_VERSION=v3`로 올렸다.

## 판단
- 수집 원문 자체는 보존한다. 지금 단계에서 원문을 삭제하면 재처리/검증/파서 개선이 어려워진다.
- 대신 AI 입력 단계에서 핵심 표/리스크 문구만 추출해 비용과 시간을 줄이는 쪽이 안전하다.
